Projects

Lunabotics · Controls

CMU Moon Miners

Software Controls Lead on CMU's NASA Lunabotics team, an 80-person team unified in goal of building an autonomous lunar excavation rover. I direct 20 software members across sub-teams, owning the GitHub workflow, code review, and release deadlines, and wrote the C++ and Python ROS 2 autonomy foundation so every sub-team runs identical nodes in simulation and on hardware. We delivered the first autonomous scoring run by any rookie team in Lunabotics history and were named Best Rookie Team 2026. I have been integrating LiDAR point-cloud SLAM for obstacle detection, localization, and navigation.

  • ROS 2 · C++ · LiDAR SLAM

Research · Teleoperation

Momentum Robotics Lab

Research assistant on COSTAR, a long-range teleoperation system for 7-DoF manipulators. I built a modular iOS interface in Swift that drives several arm models from one controller, replacing the separate app each arm used to need, and packaged the stack with Zenoh and Docker so operators could run it off-site without rebuilding from source. Real-time control and fail-safes were validated in MuJoCo before any hardware run.

  • Swift · Zenoh · Docker
  • MuJoCo
  • Jun 2025–May 2026

Personal · Computer Vision

Magic Mirror Optical Illusion

A personal summer project that was mostly an exercise in pinhole camera mathematics, tracking your eyes to make a pseudo-3D effect on a normal screen. I created this as a base for a future Raspberry Pi-based magic mirror design with lifestyle widgets with a 3D background effect.
